🐾 Patas & Lar

Site de adoção responsável de animais. A plataforma conecta quem quer adotar
com quem tem um bichinho precisando de um lar, e também permite doar itens.

✨ Funcionalidades

Para adotantes e doadores
- Cadastro e login de usuários
- Cadastro de animais para adoção, com foto
- Listagem de animais com filtros por espécie, porte, raça, sexo e idade
- Formulário de adoção com perguntas sobre a residência, a rotina e a experiência com animais
- Notificações para o dono do animal responder aos pedidos de adoção
- Página de doações, com tela de confirmação e instruções de entrega
- "Minhas doações" para acompanhar o status de cada doação

Para o administrador
- Login exclusivo de administrador
- Painel de solicitações de adoção 
- Painel de doações

Linguagens utilizadas

- PHP 5.3 (compatível com o EasyPHP)
- MySQL, com acesso via PDO
- HTML, CSS e JavaScript
